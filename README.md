# PressJobs - منصة الوظائف الإعلامية

موقع يربط الصحفيين والمصورين وصناع المحتوى وأصحاب المونتاج مع القنوات الإعلامية والمواقع الإخبارية.

## التثبيت والتشغيل

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. تشغيل الموقع
```bash
python app.py
```

### 3. فتح المتصفح
```
http://localhost:5000
```

## أنواع الحسابات

- **كادر إعلامي**: صحفي، مصور، صانع محتوى، مونتير، مذيع، مراسل
- **قناة / موقع إخباري**: تنشر الوظائف وتستقبل طلبات التقديم
